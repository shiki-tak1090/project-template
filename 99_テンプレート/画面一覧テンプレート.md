**書き方のルール**

- 画面 ID は `<機能の略号>-<2 桁の連番>` の形で採番する（例: `MEM-01`）。一度採番した ID は、画面を廃止しても再利用しない
- 各画面に、根拠となる要件 ID を書く
- 画面ごとの領域の並びと表示する情報は `07_画面仕様書/画面仕様書.md` に、項目の型や桁、メッセージの文言、どの場面でどのメッセージを出すかは詳細設計に書く。この文書には、画面の役割と主な操作だけを書く
- 決まっていないことは【要確認】と書く
