# {{プロジェクト名}} ドキュメント

{{プロジェクト名}} の公式ドキュメントリポジトリです。要件定義書・設計書・API 仕様・DB 設計・議事録など、プロジェクトにかかわるドキュメントをすべてここで管理します。

## 参画手順

途中から参画する人は、次の手順で開発環境を整えます。

### 1. 手で行うこと（最初の 1 回だけ）

`/project-init` は Claude Code の中で動くため、次の 3 つだけは手で用意します。

1. Git と Claude Code をインストールし、{{Gitの置き場所}} に接続できるようにする（SSH の鍵の登録など）
2. 親フォルダを作り、その中にこのリポジトリを clone する

   ```bash
   mkdir xxxxx
   ```

   ```bash
   git clone {{ドキュメントリポジトリのclone元}} xxxxx/xxxxx_document
   ```

   リポジトリが非公開の場合は、{{Gitの置き場所}} でアクセス権（GitHub ならリポジトリへの招待、Azure DevOps ならプロジェクトへの参加）がないと clone できません。clone できなければ、{{管理者}}に依頼してください。

3. `xxxxx/xxxxx_document` で Claude Code を起動する。フォルダを信頼するか聞かれたら信頼する（信頼すると、プロジェクトで使うプラグインが読み込まれる）

### 2. `/project-init` を実行する

`xxxxx/xxxxx_document` で起動した Claude Code で、`/project-init` を実行します。次のことを行います。

- [リポジトリ一覧](00_プロジェクト概要/リポジトリ一覧.md) にあるコードのリポジトリを、親フォルダの下に clone する
- 各リポジトリが `CLAUDE.md` の「開発環境の前提」で宣言している言語やツールが入っているかを確認し、足りないものを（了承を得てから）インストールする
- 親フォルダに `CLAUDE.md` を置く
- プラグインと、PR を作るツール（{{PRを作るツール}}）のログインを確認する
- 各リポジトリで最初に実行するコマンド（依存パッケージのインストールなど）を案内する

依存パッケージのインストール（`npm install` など）は、`/project-init` では行いません。案内されたコマンドを、各リポジトリで自分で実行してください。

何度実行しても問題ありません。リポジトリやツールが増えたときなどに、もう一度実行してください。

### 3. 参画したらやること

開発環境とは別に、チームの一員として次のことを済ませてください。

- Backlog のプロジェクト（`{{Backlogのプロジェクトキー}}`）に参加する。タスクの管理と、PR のレビューのやり取りは Backlog で行います。参加していなければ、{{管理者}}に依頼してください
- [CLAUDE.md](CLAUDE.md) の「Git 運用」と「タスク管理」を読む
