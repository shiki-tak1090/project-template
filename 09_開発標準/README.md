# 開発標準

開発チームが実装の方針をそろえるための決まりを管理します。**このフォルダは社内向けで、納品物ではありません。** 顧客に説明するシステムの構成と方式は `02_基本設計/方式設計.md` に書きます。

`開発標準.md` は、各コードリポジトリの実装規約の正本です。`/project-dev:setup-architecture` が、ここから各コードリポジトリの `CLAUDE.md` の規約と、規約を検査する仕組みを作ります。
